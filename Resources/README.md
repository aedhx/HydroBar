# Resources

This folder contains visual assets for the HydroBar project.

## Images

- `hero-banner.png` - Main hero banner/logo for the README
- `main-view.png` - Screenshot of the main hydration tracking interface
- `statistics-view.png` - Screenshot of the statistics dashboard
- `settings-view.png` - Screenshot of the settings/configuration interface
- `notifications.png` - Screenshot showing notification functionality
- `HydroBar-icon.png` - Application icon
- `DMG-background.png` - Background image for DMG distribution

## Usage

These images are referenced in the main README.md file. Make sure to add the actual image files to this directory for them to display correctly on GitHub.
