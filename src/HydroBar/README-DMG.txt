HydroBar - Guide d'installation

📦 INSTALLATION

1. Glissez "HydroBar.app" dans le dossier "Applications"
2. Ouvrez le dossier Applications et lancez HydroBar
3. Lors de la première ouverture, macOS peut afficher un avertissement de sécurité :
   - Faites un clic droit sur HydroBar.app > "Ouvrir"
   - Cliquez sur "Ouvrir" dans la fenêtre de sécurité

🔐 AUTORISATIONS REQUISES

HydroBar nécessite certaines autorisations pour fonctionner correctement :

1. Notifications
   - Ouvrez Préférences Système > Notifications
   - Activez les notifications pour HydroBar

2. Accessibilité (pour les raccourcis clavier globaux)
   - Ouvrez Préférences Système > Sécurité et confidentialité > Confidentialité
   - Sélectionnez "Accessibilité"
   - Ajoutez HydroBar et cochez la case

✨ FONCTIONNALITÉS

• Suivi quotidien de votre hydratation
• Rappels personnalisables
• Statistiques détaillées (7 jours et 30 jours)
• Raccourcis clavier globaux
• Synchronisation avec le Focus Mode macOS
• Interface moderne et intuitive

📝 NOTES

• HydroBar fonctionne comme une application de barre de menu
• L'icône apparaît dans la barre de menu en haut de l'écran
• Cliquez sur l'icône pour ouvrir le panneau principal
• Clic droit pour accéder au menu contextuel

🐛 PROBLÈMES ?

Si vous rencontrez des problèmes :

1. Vérifiez que toutes les autorisations sont accordées
2. Redémarrez l'application
3. Vérifiez que vous utilisez macOS 12.0 ou supérieur
